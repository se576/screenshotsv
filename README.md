# スクリーンショット

Windows 向けのローカル完結型スクリーンショットアプリ。
Python + PySide6 製。外部サービス不要、撮影・注釈・保存をすべてオフラインで行えます。

---

## 機能

### キャプチャ
| 操作 | ショートカット | 説明 |
|------|--------------|------|
| 全画面キャプチャ | `F1` / `Ctrl+Alt+F` | プライマリモニターをキャプチャ |
| 範囲選択キャプチャ | `F2` / `Ctrl+Alt+R` | ドラッグで任意範囲を選択（`Esc` でキャンセル） |
| ウィンドウキャプチャ | `F3` / `Ctrl+Alt+W` | マウスオーバーしたウィンドウをワンクリックでキャプチャ |
| 遅延キャプチャ | スピンボックスで 0〜30 秒 | カウントダウン後にキャプチャ |

- **マルチモニター対応** — 範囲選択・ウィンドウ選択は全モニターにまたがる仮想デスクトップに対応

### 編集
| ツール | ショートカット | 説明 |
|--------|--------------|------|
| 閲覧 | `V` | 編集なしで画像を確認 |
| 選択 | `S` | 注釈をクリックして選択・移動・リサイズ・削除 |
| 矩形 | `R` | 枠線の矩形を描画 |
| 塗りつぶし四角形 | `F` | 塗りつぶした四角形を描画 |
| テキスト | `T` | ダブルクリックで文字を配置 |
| トリミング | `C` | ドラッグした範囲に画像を切り抜き（範囲外は暗転表示・サイズ表示付き） |
| Undo | `Ctrl+Z` | 操作を元に戻す（トリミングも復元可・回数表示付き） |
| Redo | `Ctrl+Y` | 操作をやり直す（回数表示付き） |

- 色・線幅・フォントサイズをツールバーで調整（**線幅は 0.1px 単位**）
- 選択中の注釈の色をピッカーで直接変更、`Delete` キーで削除

### 保存
| 操作 | ショートカット | 説明 |
|------|--------------|------|
| 即時保存 | `Ctrl+Shift+S` / `Ctrl+Alt+S` | プロファイルの保存先へ自動保存 |
| 名前を付けて保存 | `Ctrl+S` | ファイル名・形式（PNG/JPEG）を指定して保存 |
| クリップボードにコピー | `Ctrl+C` | 注釈込みの画像をコピー |

- 保存成功時はトースト通知（トレイ格納中はトレイ通知）
- 保存後にフォルダを自動で開くオプションあり
- 保存時に外枠エフェクトを自動適用（色・幅を設定可能、**幅は 0.1px 単位**）

### グローバルホットキー
アプリが最小化・トレイ格納中でもキャプチャ・保存が可能。
各アクションに最大 2 つのキーを登録でき、スロットごとに使用するプロファイルを指定できます。

- **撮影後の動作を選択可能**（⚙設定 → ホットキー撮影後の動作）
  - **編集画面に表示する**（デフォルト）: 撮影後に編集画面が前面に出て、トリミング・注釈してから保存できる
  - **即時保存する**: 従来どおりプロファイルの保存先へ直接保存（連続撮影向き）
- 「即時保存」アクション + プロファイル指定のホットキーで、**編集中の画像をそのプロファイルの保存先へワンキー保存**（撮影 → 編集 → 保存のキーボード完結フロー）
- 連打による多重キャプチャは自動で抑止

### プロファイル
保存先フォルダ・バックアップ設定・エフェクト設定を「プロファイル」として複数管理できます。

| 設定項目 | 内容 |
|---------|------|
| 保存先フォルダ | プロファイルごとに個別のフォルダを指定 |
| バックアップ | キャプチャ時に無編集の原本を `backup/` へ自動保存 |
| 保存後フォルダを開く | 保存完了後にエクスプローラーを自動起動 |
| 外枠エフェクト | 保存時に指定色・幅の外枠を自動追加 |

### 常駐・多重起動
- ×ボタンの動作を選択可能（毎回確認 / トレイに常駐 / 終了）。⚙設定メニューからいつでも変更可
- タスクトレイから各種キャプチャ・ウィンドウ表示・終了を操作
- **多重起動しても常駐プロセスは 1 つだけ** — 2 回目の起動は既存ウィンドウを前面表示して終了
- exe 実行時はトレイメニューからログオン時の自動起動（タスクスケジューラ）を登録可能

## 動作環境

- **OS**: Windows 10 / 11
- **exe 版**: Python 不要。`screenshotsv.exe` 単体で動作
- **ソース実行**: Python 3.11 以上（開発は 3.14）

---

## 使い方（exe 版）

`screenshotsv.exe` をダブルクリックするだけで起動します。

- 起動時に UAC（管理者権限）の確認が表示されます。管理者権限アプリが前面にあってもグローバルホットキーを効かせるためです（拒否しても通常権限で動作継続）
- 初回起動時に SmartScreen の警告が出た場合は「詳細情報 →実行」で起動できます

## セットアップ（ソースから）

```bash
# 依存パッケージのインストール
pip install -r requirements.txt

# 起動
python screenshotsv.py
```

## exe のビルド

```bash
pip install pyinstaller
python -m PyInstaller screenshotsv.spec --noconfirm
# → dist/screenshotsv.exe（単一ファイル）
```

---

## 設定ファイル

設定は `~/.screenshotsv/config.json` に自動保存されます（原子的書き込みで破損防止）。
アプリ終了後も引き継がれ、次回起動時に復元されます。

## ファイル構成

```
screenshotsv/
├── screenshotsv.py          # エントリポイント（UAC 昇格・多重起動ガード）
├── screenshotsv.spec        # PyInstaller ビルド定義
├── requirements.txt
└── app/
    ├── main_window.py       # メインウィンドウ・トレイ・保存フロー
    ├── editor.py            # 編集キャンバス（注釈・トリミング・Undo/Redo）
    ├── capture.py           # 全画面・範囲選択キャプチャ
    ├── window_selector.py   # ウィンドウ選択オーバーレイ
    ├── hotkeys.py           # グローバルホットキー管理（pynput）
    ├── hotkey_dialog.py     # ホットキー設定ダイアログ
    ├── profile_dialog.py    # プロファイル管理ダイアログ
    ├── save_options_dialog.py  # 保存設定ダイアログ
    ├── annotations.py       # 注釈データクラス
    ├── settings.py          # 設定の読み書き
    └── ui_utils.py          # 共有UIユーティリティ
```
