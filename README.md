# スクリーンショット

Windows 向けのローカル完結型スクリーンショットアプリ。
Python + PySide6 製。外部サービス不要、撮影・注釈・保存をすべてオフラインで行えます。

---

## 機能

### キャプチャ
| 操作 | ショートカット | 説明 |
|------|--------------|------|
| 全画面キャプチャ | `F1` / `Ctrl+Alt+F` | 全モニターを一枚に収めてキャプチャ |
| 範囲選択キャプチャ | `F2` / `Ctrl+Alt+R` | ドラッグで任意範囲を選択（`Esc` でキャンセル） |
| ウィンドウキャプチャ | `F3` / `Ctrl+Alt+W` | マウスオーバーしたウィンドウをワンクリックでキャプチャ |
| 遅延キャプチャ | スピンボックスで 0〜30 秒 | カウントダウン後にキャプチャ |

- **マルチモニター対応** — 全モニターにまたがる仮想デスクトップをそのまま選択範囲に使用

### 注釈（アノテーション）
| ツール | ショートカット | 説明 |
|--------|--------------|------|
| 閲覧 | `V` | 編集なしで画像を確認 |
| 選択 | `S` | 注釈をクリックして選択・移動・リサイズ・削除 |
| 矩形 | `R` | 枠線の矩形を描画 |
| 塗りつぶし四角形 | `F` | 塗りつぶした四角形を描画 |
| テキスト | `T` | ダブルクリックで文字を配置 |
| Undo | `Ctrl+Z` | 操作を元に戻す（回数表示付き） |
| Redo | `Ctrl+Y` | 操作をやり直す（回数表示付き） |

- 色・線幅・フォントサイズをツールバーで調整
- 選択中の注釈の色をピッカーで直接変更
- `Delete` キーで選択中の注釈を削除

### 保存
| 操作 | ショートカット | 説明 |
|------|--------------|------|
| 即時保存 | `Ctrl+Shift+S` / `Ctrl+Alt+S` | プロファイルの保存先へ自動保存 |
| 名前を付けて保存 | `Ctrl+S` | ファイル名・形式（PNG/JPEG）を指定して保存 |
| クリップボードにコピー | `Ctrl+C` | 注釈込みの画像をコピー |

- 保存成功時はトースト通知を表示
- 保存後にフォルダを自動で開くオプションあり
- 保存時に外枠エフェクト（色・幅を設定可能）を自動適用

### グローバルホットキー
アプリが最小化・背面にある状態でもキャプチャ・即時保存が可能。
各アクションに最大 2 つのキーを登録でき、スロットごとに使用するプロファイルを指定できます。

### プロファイル
保存先フォルダ・バックアップ設定・エフェクト設定を「プロファイル」として複数管理できます。

| 設定項目 | 内容 |
|---------|------|
| 保存先フォルダ | プロファイルごとに個別のフォルダを指定 |
| バックアップ | キャプチャ時に無編集の原本を `backup/` へ自動保存 |
| 保存後フォルダを開く | 保存完了後にエクスプローラーを自動起動 |
| 外枠エフェクト | 保存時に指定色・幅の外枠を自動追加 |

## 動作環境

- **OS**: Windows 10 / 11
- **Python**: 3.11 以上推奨

---

## セットアップ

```bash
# 依存パッケージのインストール
pip install -r requirements.txt

# 起動
python main.py
```

> **注意**: `keyboard` ライブラリはグローバルホットキーの登録に管理者権限が必要な場合があります。
> ホットキーが効かない場合は「管理者として実行」で起動してください。

---

## 設定ファイル

設定は `~/.screenshotsv/config.json` に自動保存されます。
アプリ終了後も引き継がれ、次回起動時に復元されます。

---

## ファイル構成

```
screenshotsv/
├── main.py                  # エントリポイント
├── requirements.txt
└── app/
    ├── main_window.py       # メインウィンドウ
    ├── editor.py            # 注釈キャンバス
    ├── capture.py           # 全画面・範囲選択キャプチャ
    ├── window_selector.py   # ウィンドウ選択オーバーレイ
    ├── hotkeys.py           # グローバルホットキー管理
    ├── hotkey_dialog.py     # ホットキー設定ダイアログ
    ├── profile_dialog.py    # プロファイル管理ダイアログ
    ├── save_options_dialog.py  # 保存設定ダイアログ
    ├── annotations.py       # 注釈データクラス
    ├── settings.py          # 設定の読み書き
    └── ui_utils.py          # 共有UIユーティリティ
```
